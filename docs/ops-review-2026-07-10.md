# 2026-07-10 生产运行时加固与发布记录

## 范围

本次发布修复线上审查发现的运行时问题。发布包在本地 Linux Docker 环境构建，服务器只解包、预检和切换；未在 2GB 服务器执行 `npm ci` 或 Next.js 构建，也未运行 seed 或初始化数据库。

## 已上线修复

- AI 思路请求在 Nginx 的专用代理路径使用 600 秒读取/发送超时，避免上游 DeepSeek 长推理被 Nginx 默认超时截断。
- standalone 服务默认仅监听 `127.0.0.1:3000`；公网通过 Nginx 的 80 端口访问，3000 不再直接可达。
- Nginx 只向应用传递自身观察到的客户端地址；登录限流不再信任可由客户端伪造的左侧 `X-Forwarded-For`。
- AI 思路服务端增加同一学生同时只能执行一个请求、全局并发上限和清理逻辑，避免跨题点击堆积上游调用。
- Docker Judge 使用非 root 用户、内存与 swap 上限以及只读根文件系统等隔离参数；线上已完成编译运行冒烟验证。
- 考试提交以服务端接收时间判断是否超时，并在学生成绩页和管理员记录页按截止时间重新计算展示成绩，避免截止瞬间的评分竞争导致错误展示。
- 当前生产目录、保留回滚目录、SQLite 数据库与 `.env` 权限均收紧为仅 root 可读写（目录 `750`，敏感文件和数据库备份 `600`）。
- 客观题提交确认和 AC 提示使用正确的无障碍语义，不再声明为会抢占焦点的模态对话框。
