数据实际存在哪里？

正式提交、逐测试点结果、考试记录、任务进度以及反馈，均通过 Prisma 存在生产 SQLite 数据库 /www/oj/prisma/prod.db；截图以私有二进制附件入库。生产备份位于 /www/backups。编辑器草稿留在浏览器，不等同于正式提交。

02

学生点击提交之后？

服务端先验身份和作答上下文。编程题入进程内队列，在 Docker 中编译、运行；选择判断题由服务端直接判分。结果和明细写入数据库，再按考试或专项规则更新进度；学生收到经过服务端脱敏的可见结果。试运行不生成正式提交。
