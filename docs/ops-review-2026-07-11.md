# 2026-07-11 竞技学院视觉与天梯升级记录

## 上线范围

本次将登录页、学生端和管理员端统一为“竞技学院”视觉语言，重点升级学生首页与双端天梯榜：

- 学生首页改为“今日任务 + 段位成长”构图，集中展示刷题入口、考试入口、当前排名和晋级进度。
- 天梯榜新增前三名领奖台、段位徽章和一次性入场动效。
- 学生榜新增“我的战绩”、距前一名积分差和下一段位进度。
- 第四名以后在桌面端使用排名表，在移动端使用纵向卡片。
- 管理员首页升级为教学竞技控制台，管理员天梯保留头衔来源和完整统计信息。
- 公共导航增加当前页面指示，登录、按钮、表单、表格与空状态使用统一视觉和快速反馈。
- 所有新增动画支持 `prefers-reduced-motion`，不使用持续循环动画，也未新增动画依赖。

本次没有修改 Prisma、排名算法、积分规则、考试逻辑、AI 助手、Docker Judge 或 Monaco 自动建议策略。
