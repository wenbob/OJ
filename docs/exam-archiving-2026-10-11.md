# 考试归档与历史保护

考试使用独立的 `archivedAt` 标记归档，业务状态仍为 `draft`、`published`、`ended`。归档和取消归档只影响管理列表，不删除考试、题单快照、学生考试记录、提交、代码、积分或通过状态。

## 操作规则

| 情况 | 允许操作 |
| --- | --- |
| 无考试记录、关联提交、AI 对话或归档审计的草稿 | 编辑、发布、永久删除 |
| 已发布考试 | 查看记录、结束；没有学生记录时可取消发布 |
| 已结束考试 | 查看历史、归档 |
| 已归档考试 | 查看记录、取消归档；仍保持已结束 |

老师只能操作自己创建的考试，管理员可操作全部。学生不能归档、取消归档或删除考试。老师对他人或空归属考试统一得到 404。

后台考试列表提供“未归档／已归档”切换、参加人数、最近归档操作者与时间。归档列表不提供编辑和进入做题入口；直接访问归档考试的编辑、练习页面会进入考试记录页。记录页可查看最近十次归档操作。取消归档不恢复考试、不重置倒计时、不允许重新发布。

学生在 `/student/exams?view=history` 查看自己的历史考试，按考试记录分页，包含从未提交代码的考试。历史成绩继续使用发布快照和原计分规则；结果页提供“查看本场提交与代码”，只查询本人在本场考试的提交。学生仍不能读取客观题标准答案、编程隐藏测试或他人的记录。

关联缺失的旧提交保留代码和原始数据，列表标注“历史考试关联缺失”，不按题目名称或时间猜测考试归属。

## API 与数据保护

| 接口 | 行为 |
| --- | --- |
| `POST /api/admin/exams/[id]/end` | 结束已发布考试并结算未完成记录；重复结束安全重试 |
| `POST /api/admin/exams/[id]/archive` | 归档已结束且可结算的考试；重复请求不追加审计 |
| `DELETE /api/admin/exams/[id]/archive` | 取消归档；重复请求不追加审计 |
| `DELETE /api/admin/exams/[id]` | 仅永久删除无历史关联的草稿，其他情况返回 409 |
| `GET /api/admin/exams?view=archived` | 返回当前后台账号有权查看的归档考试 |

状态复核与写入置于同一事务。归档使用条件更新，操作与 `ExamArchiveAudit` 同事务保存。审计追加归档或取消归档动作、时间、操作者 ID 与用户名/角色快照；删除操作账号后保留快照。

SQLite 迁移 `0024_exam_archiving` 增加归档字段、列表索引、归档审计表及三个保护触发器：有历史的考试不能物理删除，归档必须保持已结束，已结束不能改回草稿或已发布。

生产沿用单 Node 进程和进程内 Judge 队列。考试在途提交按考试登记，范围覆盖校验、排队、评测、落库和成绩刷新；归档与登记按考试串行。在途提交存在时归档返回 409，显示等待提示。已接收且按时的提交继续按服务端收到请求的时间计分，评测结束后刷新已交卷成绩；失败路径释放在途登记。

进程内协调状态通过 `globalThis` 在不同路由包之间共享。若未来改为多进程或多机部署，必须先将 Judge 和考试在途协调改为共享机制；当前功能不能据此宣称支持多实例归档协调。

## 发布与回退

迁移只新增字段、表、索引与保护触发器，既有业务行不回填、不删除。发布前验证一致性备份，切换后在新 `/www/oj` 应用迁移，并替换本次 Linux 构建生成的 Prisma Client。迁移前后逐表比较旧字段和业务行，确认新审计表为空、三个保护触发器存在、完整性与外键检查通过。

回退时保留最新数据库及新增保护规则，不删除归档字段/审计表，不用发布前数据库覆盖后续学习数据。旧代码回退后归档列表功能可能暂时不可用，已结束状态和数据库删除保护仍须保留；正常恢复功能应使用兼容归档字段的修复版本。

## 历史关联核查

工具 `scripts/audit-exam-history.py` 以 `mode=ro`、`query_only` 和读事务打开来源及备份。它用提交 ID、账号/题目 ID、收到时间、语言、代码哈希和结果匹配原提交，进一步核对考试创建身份、题单与学生考试记录；报告不保存代码、密码、标准答案或密钥。

```text
python scripts/audit-exam-history.py --db prisma/dev.db --out tmp/exam-history.json
python3 scripts/audit-exam-history.py --db /www/oj/prisma/prod.db --backup-dir /www/backups --out /tmp/oj-exam-history.json
```

报告是恢复候选清单，不执行数据修复。具体修复须先核对证据、明确可恢复字段和影响范围；完整计分快照缺失时不能保证还原原成绩。
