# 竞技学院 UI 接入记录

2026-10-01 将已认可的纸张风格设计接入实际 Next.js 页面。保留米色、深墨、钢蓝、黏土橙和原有段位徽章，采用 12px 卡片、7px 按钮与更轻的边框、字重和阴影。

本页保留该阶段的实现与验收记录。2026-10-02 后续完成的三端共用组件、题目入口与响应式优化见 [三端 UI 统一说明](ui-unification-2026-10-02.md)，正式部署与 GitHub 提交见 [2026-10-02 发布记录](ops-review-2026-10-02-ui-unification.md)。2026-10-07 的本地样例对比与提交结果简化见 [编程反馈说明](programming-feedback-2026-10-07.md)。

## 已实现

- 学生、老师、管理员共用导航增加 Lucide 图标；桌面宽度不足时换行，窄屏横向滚动并提供可点击的向右提示。当前项仍由既有路径规则判断，切页继续保留当前屏幕，仅在等待超过 100ms 时显示链接反馈。
- 全站共用按钮、输入框、卡片统一圆角、焦点和悬停反馈；普通页面仍采用 180ms / 4px 的统一入场，尊重系统减少动效设置。
- 学生首页改为欢迎语、公告、专项任务与段位、四项统计、四个常用入口、复盘与最近提交。任务进度、考试数量、积分、排名均来自既有服务；最近提交仅查询当前账号最近三条的标题、状态、类型和时间。
- 四个首页入口使用同系列透明纸雕插画。固定图片尺寸，加载失败后在原位置显示矢量图标，入口文字及链接仍可用。首页与首屏插画采用 eager 加载，奖励列表中的小图按需加载。
- 题库题型与分类按钮、已通过标签、题目标题和章节图标更清楚。公开样例增加单独复制按钮，复制成功后才显示“已复制”。
- 专项练习进度条增加可访问性属性，完成后显示绿色。任务、考试、奖励没有内容时展示说明和可用入口。
- 奖励卡片区分待领取与已领取，操作等待及积分出现均依据真实请求状态；沿用原有冷却、期限、幂等、考试限制和弹窗队列。
- 后台入口图标增加底座，减轻标题、计数和说明的字重；老师首页文案与已有权限一致。
- 修复做题页右侧网格与 AI 文本框的最小宽度，避免 Monaco 与文本框在 320px、1280px 下把页面撑宽。未调整编辑器选项、AI 请求或评测行为。

新图片与完整生成提示词见 [素材记录](ui-assets.md)。阶段 A 的演示设计稿仍保存在 [ui-preview](ui-preview/README.md)，其数据与截图独立于本次应用验收。

## 浏览器验收

使用本机 Chrome、Playwright CLI、专用 `prisma/e2e.db` 和现有 E2E 服务器。仅在隔离库中创建 UI 任务状态；未操作生产环境。截图隐藏了开发工具浮标，账号和内容均为测试数据。

| 检查 | 结果 |
| --- | --- |
| 首页 320、360、390、768、1024、1280、1440px | 页面宽度与视口一致；窄屏只在导航内部滚动 |
| 做题页上述七种宽度 | 修复后无页面横向溢出，Monaco 随容器调整 |
| 老师首页 320、390、768、1280px | 无页面横向溢出 |
| 管理员首页 320、390、1024、1280px | 无溢出；桌面导航可以换行 |
| 登录页 320、390、768、1280px | 输入框及主体无溢出 |
| 奖励页 320、390、1280px | 说明、空状态及入口无溢出 |
| 首页插画 | 四张 WebP 均成功加载并保留透明通道 |
| 图片失败 | 阻断模拟考试插画请求后出现矢量回退，文字、链接及占位尺寸保持可用；解除阻断后恢复图片 |
| 导航向右提示 | 点击后导航 scrollLeft 从 0 增加，内容确实滚动 |
| 减少动效 | 过渡与入场时长降至 0.00001s，导航采用直接滚动 |
| 任务状态 | 2/3 显示 67%；3/3 显示已完成并转为日常练习入口；无任务时不显示任务进度条 |
| 任务提醒 | 实际通过唯一入口进入专项页面，返回首页后遵循既有静默规则 |
| 无提交 | 显示第一份解答提示及日常刷题入口 |
| 样例复制 | 从按钮复制的文本为公开样例 `1 2` 及原有换行；随后显示已复制 |

首次无站点图标的测试登录页触发既有 `/favicon.ico` 404；本次插画请求正常。浏览器身份继续由 `BrowserIdentity` 读取系统设置，不额外覆盖站点图标。
