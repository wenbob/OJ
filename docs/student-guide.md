# 学生使用说明

这份说明给学生使用。你只需要会登录、找题、写 C++ 代码、提交、查看结果和参加模拟考试。

## 1. 如何登录

1. 打开平台登录页：

```text
/login
```

2. 输入老师提供的用户名和密码。
3. 点击登录。
4. 登录成功后会进入学生首页。

如果提示用户名或密码错误，请先确认是否输错；仍然无法登录时，联系老师重置密码。

同一个学生账号一次只保留最后登录的浏览器会话。新设备登录后，旧设备会提示“账号已在其他设备登录”并返回登录页；老师和管理员账号不受此限制。若换设备时正在考试，系统会先自动交卷。

## 2. 如何进入日常刷题

登录后，在学生端顶部菜单点击：

```text
日常刷题
```

也可以直接访问：

```text
/student/problems
```

这里会显示日常练习题目列表。

题目分为“编程题”和“选择判断题”两个入口，切换题型后再按分类找题。

## 3. 如何按分类找题

题目列表顶部会显示分类，例如：

```text
全部
基础语法
条件判断
循环结构
数组
字符串
函数
综合练习
```

使用方式：

1. 点击“全部”可以查看所有题目。
2. 点击某个分类，只显示该分类下的题目。
3. 每道题会显示题目标题、难度、分类和“我的提交”数量。
4. “我的提交”只统计你自己的日常刷题提交，不显示其他同学在这道题上的提交次数。
5. 日常或考试中只要曾经通过过这道题，整行会显示为淡绿色并带“已通过”标签，按钮显示“再次练习”。
6. 题目列表默认每页展示 50 道题；如果题目很多，可以使用上一页、下一页翻页。

日常提交和考试提交记录仍默认每页展示 20 条。

题目和分类标签的展示顺序由管理员统一安排。学生端只按该顺序浏览和筛选，不提供自行调整排序的入口。

## 4. 如何查看题目

在题目列表中点击题目的进入按钮，会打开题目详情页。

题目详情页会显示：

- 题目标题
- 难度
- 分类
- 题目描述
- 输入格式
- 输出格式
- 样例输入
- 样例输出
- 数据范围
- C++ 代码编辑器

选择判断题页面会按顺序显示多道小题，每题包含题干、A/B/C/D 选项和分值。判断题使用 A=正确、B=错误。

编程题和选择判断题都会把题面中的代码块、行内代码、列表、表格、链接和数学公式渲染成便于阅读的样式；使用 `$...$` 或 `$$...$$` 编写的公式会由 KaTeX 显示，不会直接露出公式标记。

样例标题在代码框外面，代码框里面只是真正的输入或输出内容。复制样例时，不要把“样例输入 1”这样的标题复制进去。

题目标题区域提供“复制本题”按钮。点击后会复制 Markdown 格式的完整题面，包含标题、难度、分类、题目描述、输入格式、输出格式、全部样例和数据范围。日常刷题和模拟考试答题页都可以使用。

## 5. 如何使用 Monaco Editor 写 C++ 代码

题目详情页中的代码编辑器类似 VS Code。

支持：

- C++ 语法高亮
- 行号
- Tab 缩进
- 自动缩进
- 括号和引号自动补全
- 括号匹配
- 粘贴代码时保留格式
- 暗色主题
- 代码字号调节

编辑器不会自动弹出代码提示或补全候选。它只保留基础编辑能力、语法高亮、缩进和括号/引号自动补全。

编辑器上方可以调整代码字号。字号设置会保存在当前浏览器中，下次打开仍会沿用。

选择判断题仍使用同一个编辑器，但会切换成“答案输入”模式。每行对应一道小题，只填写选项字母，例如：

```text
A
B
A
```

小写字母会自动按大写判定。不要在答案行后添加解释文字。

在电脑端做日常选择判断题时，答案编辑器会完整展开为较高的输入区域，不再出现答案区外层的横向或纵向滚动条；查看题目和答案时统一使用页面主滚动条。手机端仍按题目、答案输入的顺序自然排列。

提交选择判断答案后，结果区会立即展开每一道小题的题号、正确或错误以及“我的答案”。可以收起后再次展开，也可以点击“查看完整提交详情”以后重新查询。学生端不会显示标准答案。

第一次打开题目时，如果没有草稿，会显示默认 C++ 模板。

如果你修改过代码，平台会自动把草稿保存到浏览器本地。刷新页面后，之前写的代码通常还会保留。

日常刷题按题目保存草稿。模拟考试按“考试 + 题目”保存草稿，切换考试题目时会显示该题自己的代码，不会继续显示上一道题的代码。

### AI 学习助手

只有老师为你的账号单独开通 AI 权限，并且日常练习或当前考试的 AI 开关也已开启时，编程题编辑器上方才会显示 AI 学习助手。

- 理解题目：先用简单的话说明题目要完成什么，再按题目需要分步骤讲思路。
- 下一步提示：结合编辑器里的最新代码，只告诉你现在最应该完成的一步。
- 检查当前代码：指出最多三个问题、所在行和检查方向，不替你重写代码。
- 自由提问：可以继续问当前题目的输入输出、解题步骤、代码问题或直接相关的 C++ 知识。

AI 只辅导当前题目，不回答无关问题，也不提供完整代码、可以直接复制的代码语句、最终答案或隐藏测试点。三个入口和自由提问共用同一个账号触发间隔，具体秒数由管理员设置；页面会显示服务器返回的实际倒计时。

管理员可以调整理解题目、下一步提示、检查代码和自由提问的教学表达方式，但不能关闭上述安全保护；学生页面不会显示系统提示词原文。

请求发出后会立即显示“AI 已收到问题”，并持续更新已经思考的时间。AI 完成并通过安全检查后，提示会逐段显示出来；难题需要较长时间时可以继续等待，不要重复点击。

当前浏览器按账号、题目和考试保留最近对话，刷新后可以恢复，换账号、换题或换考试不会串记录。老师端会保留学生实际看到的提问和 AI 回复用于辅导；点击“清空对话”只清空当前面板，不删除老师端历史。平台不会在对话记录中保存代码快照、完整 Prompt 或模型内部推理。

### 选择判断题 AI 解析

当管理员开启选择判断 AI 主开关和学生总开关，并且老师为你的账号开通“选择判断 AI”权限后，日常刷题或专项练习中的每道小题会提供独立 AI 解析。你必须先提交一次当前整套选择判断题，无论答对或答错，才会解锁这些按钮；考试提交不能用于解锁。

第一次进入且尚未提交时，页面不会提前展示空白 AI 回答面板，只展示完整答案输入区。提交后页面会自动定位到“逐题结果”，明确显示“答对几题、答错几题、共几题”，并列出每道题的对错和自己的答案；随后 AI 面板解锁，页面刷新切换布局时本次结果仍会保留。AI 面板在上、答案输入在下，答案区不使用独立滚动条。

每次只能查看当前点击小题的正确答案、整体思路、各选项分析和知识点，不会一次展示整套答案。解析由全平台共享；点击“重新生成”并确认后会按管理员设置的学生刷新间隔调用模型，成功后所有学生、老师和管理员都会看到新版本，失败时仍保留旧解析。有效共享解析的普通读取不占用刷新间隔。

正式考试答题页和考试结果页始终不提供选择判断 AI；即使你在其他页面已经具备权限，考试进行中也不能通过接口查看本场题目的解析。学生使用记录会保留实际看到的清洗后解析和调用统计，但不会保存内部提示词、模型推理或 API Key。

选择判断解析的讲解风格由管理员统一设置，但正确答案始终以题库数据库为准，不会由自定义提示词或模型自行改写。

### 运行样例与自定义输入

编程题编辑器下方提供两种提交前检查方式：

- 运行样例：一次运行题目展示的全部公开样例，每组会标记“匹配”或“不匹配”。不匹配时可以对照样例输入、标准输出和程序输出。
- 自定义输入：自己填写一组输入，也可以留空；系统只展示程序实际输出和运行情况，不判断答案正确或错误。

试运行完成后页面会自动移动到试运行结果。它不会产生正式提交记录，不影响积分、天梯、错题本、考试分数和专项练习进度，也不会出现通过动画。每次试运行结束后需要等待 5 秒；如果正式提交也在等待，系统会优先处理正式提交。

专项练习和编程考试中也可以使用这两个功能。考试未开始、已经交卷、已经超时或老师已结束考试时不能继续试运行。选择判断题不显示试运行区域。

请记住：公开样例全部匹配只说明程序通过了题面展示的例子，不代表隐藏测试点都正确。检查完成后仍要点击“提交代码”。

## 6. 如何提交代码

1. 在编辑器中写好 C++17 代码。
2. 点击“提交代码”。
3. 等待评测完成。
4. 页面会显示评测状态、通过测试点数量、运行时间和本次程序输出。
5. 如果需要看每个测试点的输入、你的输出和标准输出，点击“查看详情”。

如果题目通过，页面中央会短暂弹出“你通过了此题”的提示图，大约 1 秒后自动消失。

注意：

- 提交前请确认代码能从标准输入读取数据。
- 不要在代码里写死样例答案。
- 不要使用需要网络、文件系统或系统权限的代码。

## 7. 评测状态是什么意思

### Accepted

答案正确，所有测试点都通过。

### Wrong Answer

程序能运行，但输出和标准答案不一致。

提交结果区域会优先显示第一个错误测试点的“程序输出”，可以先对照题目样例或提交详情里的标准输出排查。

常见原因：

- 算法错了。
- 输出格式不对。
- 多输出了提示语。
- 少了空格或换行。
- 只考虑了样例，没考虑其他测试点。

### Compile Error

代码编译失败。

常见原因：

- 少了分号。
- 括号不匹配。
- 变量名写错。
- 使用了不存在的函数。
- C++ 语法错误。

### Runtime Error

程序运行时出错。

常见原因：

- 数组越界。
- 除以 0。
- 递归太深。
- 程序异常退出。

### Time Limit Exceeded

程序运行超时。

常见原因：

- 死循环。
- 算法太慢。
- 循环次数过多。

如果复制失败，可以进入提交详情页，手动选中代码内容复制。

在提交记录或提交详情页点击：

```text
继续修改
```

平台会回到对应题目的详情页，并把这次历史提交的代码加载到编辑器中。

加载后可以继续修改，再次提交。

## 11. 如何参加模拟考试

点击顶部菜单：

```text
模拟考试
```

```text
/student/exams
```

这里会显示老师已经发布的考试。

如果看不到某场考试，可能是：

- 老师还没有发布。
- 考试已经结束。
- 页面需要刷新。

## 12. 如何开始考试

1. 在模拟考试列表中点击进入考试。
2. 查看考试名称、说明、题目数量和考试时长。
3. 点击“开始考试”。
4. 进入考试答题页。

同一场考试只会记录一次开始时间。进入答题页后，离开考试路由、后退、刷新、关闭标签页或退出账号都会直接自动交卷；同一场考试内切换题目不会交卷。切换浏览器标签、最小化窗口或切换其他软件也不会交卷。

如果已经交卷或超时，就不能继续答题，只能查看结果。

## 13. 如何在考试中提交

考试答题页会显示题目内容区和提交区。编程考试或一场考试包含多道大题时，会显示考试题目列表和每题状态；单大题选择判断考试会隐藏题目列表，让题面展示区域更宽。

编程考试使用方式：

1. 在题目列表中切换题目。
2. 阅读当前题面。
3. 在编辑器中写代码。
4. 点击提交。
5. 查看当前题目的评测状态。

选择判断考试使用方式：

1. 阅读题面和小题。
2. 在“答案输入”中按顺序填写答案，每行一个选项字母。
3. 点击“提交答案”。
4. 在确认提示中再次提交后视为交卷。

考试中的提交会记录到考试提交记录，不会混入日常提交记录。

提交完成后，如果页面显示题目列表，列表会更新该题的最新状态。切换到另一道题时，编辑器会加载另一道题自己的草稿。

## 14. 如何交卷

考试答题页会显示剩余时间。

编程考试完成后点击：

```text
交卷
```

选择判断考试点击“提交答案”后会出现确认提示，确认提交后即视为交卷。

交卷后：

- 不能继续提交。
- 会进入考试结果页。
- 可以查看总分和每题结果。
- 选择判断考试会显示实际计分提交中每道小题的正确或错误以及自己的答案，不显示标准答案。

如果时间到了，系统会自动结束考试并跳转结果页。

## 15. 如何查看考试结果

交卷或超时后，可以进入：

```text
/student/exams/[考试ID]/result
```

结果页会显示：

- 考试名称
- 考试状态
- 开始时间
- 交卷时间
- 总分
- 每题得分
- 每题最高状态
- 每题提交次数
- 选择判断题的逐题对错和自己的答案

当前计分规则：

```text
编程题：本场考试中有 Accepted 就获得该题满分，否则 0 分。
选择判断题：按一次提交中答对的小题分值累计，并取所有提交中的最高分；同分时结果页展示时间较新、提交 ID 较大的记录。
```

## 17. 如何查看头衔和天梯榜

点击顶部菜单：

```text
天梯榜
```

也可以访问：

```text
/student/leaderboard
```

天梯榜顶部会展示前三名领奖台，下方展示你自己的“我的战绩”、当前段位进度、距离前一名的积分差和距离第一名的积分差。第四名以后在电脑上使用排名表，在手机上使用纵向排名卡片。

榜单会显示学生的排名、头衔、自动段位、段位积分、唯一 AC 题数和 AC 总次数。页面动画只在首次进入时播放；如果系统开启“减少动态效果”，页面会直接显示最终状态。

当前计分规则：

- 每道题第一次 Accepted 计入唯一 AC 题数，并获得 10 段位积分。
- 同一题多次 Accepted 只算 1 道唯一 AC 题，不会重复加积分。
- 日常刷题提交和模拟考试提交都会计入天梯统计。
- 管理员可以为学生设置自定义头衔；自定义头衔只改变展示文案，不改变段位积分和排名。老师只能查看该头衔，不能修改。

## 18. 如何使用错题本和薄弱知识点

点击顶部菜单：

```text
错题本
```

也可以直接访问：

```text
/student/review
```

使用规则：

- 日常刷题和模拟考试里曾经答错的题都会自动收进错题本。
- 还没有通过的题显示“待攻克”，以后通过了就会自动变成“已攻克”。
- 首次提交就 `Accepted` 的题不会进入错题本。
- “薄弱知识点”会按题目分类显示已通过题数、待攻克题数和失败尝试次数。
- 点击“加载最近代码继续”可以回到日常练习并继续修改最近的日常提交。
- 如果这道错题只在考试中提交过，系统会让你重新挑战，不会把考试答案直接带到日常刷题页。

## 19. 如何完成老师布置的专项练习

点击顶部菜单：

```text
专项练习
```

也可以直接访问 `/student/assignments`。任务会分为“进行中、已完成、已归档”，并显示教师说明、截止时间和每道题的完成状态。

老师可能一次给多名同学布置同名课后练习，但系统会为每名学生生成独立题单。你看到的题目可能经过老师的个性化增删，自己的完成进度不会和其他同学互相影响。

进入或刷新学生首页时，只要有需要提醒的进行中且未完成专项练习，系统就会显示汇总提醒。提醒会列出任务标题、发布者、完成进度和截止时间，没有关闭按钮；请点击唯一的“去完成专项练习”进入任务列表。点击后进入 60 分钟静默期，期间刷新首页、退出重登或使用缓存会话都不会重复弹出。满 60 分钟后，仍在首页或再次回到首页时会重新检查；仍有未完成任务才再次提醒。老师新下发或修改任务后，会在下一次首页读取时立即提醒。做题、考试和专项练习页面不会被弹窗打断。

必须从专项练习详情点击题目进入，并在任务仍为进行中时重新提交 `Accepted`，页面才会提示“已计入专项练习”。以前做对过、从普通日常刷题入口再次做对，或在考试中做对，都不会自动抵扣本次专项任务。

老师可能在任务未归档时调整题目或顺序，页面会按老师最后保存的版本显示；移除任务题目不会删除你已经产生的提交或代码。若你正在评测时老师刚好移除了该题，本次结果仍会保存为普通练习，页面会提示它不计入专项进度。

超过截止时间仍然可以补做；老师归档任务后，题目仍可当普通日常题继续练习，但不再增加任务进度。老师永久删除已归档任务后，该任务会从列表中消失，不影响题目本身和原有提交记录。

## 20. 常见问题

### 登录失败怎么办

先检查用户名和密码是否正确。如果仍然失败，可以联系老师将密码重置为初始密码 `12345678`；重置后原登录会话会失效。

### 提交后一直等待怎么办

可能是评测队列正在运行，稍等一会儿再看。如果长时间没有结果，请联系老师检查 Docker Judge。

### 为什么样例过了，但提交是 Wrong Answer

“运行样例”只检查题面公开的例子。正式提交还会运行其他测试点，你的程序需要对所有合法输入都正确。

### 为什么不能在考试中继续提交

可能原因：

- 你已经交卷。
- 考试已经超时。
- 老师结束了考试。
- 你还没有点击开始考试。

### 为什么复制代码失败

如果浏览器拦截剪贴板权限，复制按钮可能会失败。当前平台已经为公网 HTTP 页面增加兼容复制方案；如果仍失败，可以进入提交详情页，手动选中代码复制。

### 为什么我的草稿不见了

草稿保存在当前浏览器本地。如果更换电脑、清理浏览器数据或使用无痕模式，草稿可能无法恢复。

### 可以提交哪些语言

当前平台只支持 C++17。
