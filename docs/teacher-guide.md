# 老师端使用说明

老师端用于日常教学、校题、组卷、学生管理和学情跟进。老师账号由管理员创建，登录后进入独立的 `/teacher`，不具备系统设置和全局题库维护权限。

## 1. 登录老师端

访问：

```text
/login
```

使用老师账号登录后会自动进入：

```text
/teacher
```

老师账号与管理员账号一样支持多设备同时登录。管理员修改老师密码或角色后，旧会话会失效，需要重新登录。

老师端可以读取管理员公告，但不能修改公告、站点设置、AI 服务商、模型、API 地址、思考模式或全局 AI 开关。

## 2. 老师端可以做什么

老师端提供：

- 题目练习与校题
- 使用管理员维护的现有题库组卷
- 创建和管理自己的模拟考试
- 创建学生、切换个人 AI 权限并把密码重置为固定初始值
- 查看全部学生的日常提交、考试提交、AI 使用和学情
- 给学生下发专项练习
- 查看天梯榜

老师端不会显示：

- 系统设置与 AI 模型配置
- 题目管理、题目导入、上下架、题序和分类排序
- 考试 Markdown 导入
- 老师或管理员账号管理

直接访问无权限的管理员页面会返回老师首页；直接调用无权限 API 会返回 `403`。

## 3. 题目练习与校题

页面：

```text
/teacher/practice
/teacher/practice/problems/[id]
```

老师可以查看管理员维护的编程题和选择判断题，运行公开样例、使用自定义输入并正式提交校题。选择判断题会显示标准答案。管理员开启独立的“选择判断题 AI 解析”后，每道小题答案旁会出现“AI 解析”：右侧上方约 70% 显示整体思路和逐项分析，下方约 30% 保留答案输入。解析在管理员和老师之间共享；老师可以读取有效解析或生成缺失解析，但不能强制重新生成。

题目练习默认每页展示 50 道题；日常提交和考试提交仍默认每页展示 20 条。

当前老师账号曾经 `Accepted` 的题目会持续显示“已通过”，后续失败不会取消。旁边的“查看通过代码”或“查看通过答案”会打开该老师最近一次 Accepted 的提交详情。

老师不能编辑、导入、下架或重新排序题目。题目和分类顺序只读跟随管理员保存的顺序。

## 4. 创建和管理自己的考试

页面：

```text
/teacher/exams
/teacher/exams/new
/teacher/exams/[id]/edit
/teacher/exams/[id]/practice
/teacher/exams/[id]/records
```

新建考试会自动记录当前老师为创建者。老师可以：

- 设置考试名称、说明、时长、题型和考试 AI 开关
- 搜索管理员维护的现有题目并组卷
- 调整考试内部题序和分值
- 发布、取消发布、结束或删除自己的考试
- 进入练习模式校题
- 查看自己的考试记录

考试列表会在标题旁显示“出卷人：当前老师用户名”，表示创建人/归属账号，不表示最后点击发布的人。老师只能查看和维护自己创建的考试。其他老师、管理员创建的考试以及升级前没有创建者记录的历史考试，对老师统一显示为不存在；管理员仍可管理全部考试，历史无归属考试会显示“出卷人：未记录”。

老师不能通过 Markdown 给考试导入题目，因为该流程可能创建全局题目。需要新题时，请先由管理员在题目管理中导入或创建，再由老师从现有题库添加。

## 5. 管理学生账号

页面：

```text
/teacher/users
```

老师可以：

- 查看全部学生账号
- 创建学生账号；初始密码固定为 `12345678`
- 开通或关闭学生个人 AI 权限
- 点击“重置密码”把学生密码恢复为 `12345678`

新增学生时 AI 权限默认开启，可以在创建前取消。老师不能修改学生用户名、角色或自定义头衔，也不能删除学生；管理员设置的头衔和系统自动段位仍会在列表中只读显示。老师也不能查看、创建、修改、提升或删除老师和管理员账号。学生个人 AI 权限只是第一层开关；还需要管理员开启日常练习 AI，或老师在自己的考试中开启考试 AI，学生才能使用。

老师不能查看原密码，也不能输入任意新密码。点击“重置密码”并确认后，系统会把密码重置为 `12345678`，同时使学生旧会话失效。桌面端新增表单会在视口内自适应跟随，移动端保持普通布局。

## 6. 提交记录

页面：

```text
/teacher/submissions
/teacher/exam-submissions
/teacher/submissions/[id]
```

老师可以查看全部学生的日常和考试提交，也可以查看自己在题目练习中产生的校题提交。

老师不能查看其他老师或管理员的校题代码。筛选和复制代码入口都会遵守同一权限范围。

## 7. 学情与专项练习

页面：

```text
/teacher/learning
/teacher/learning/[studentId]
```

老师可以查看全部学生的编程题学情、AI 聚合摘要、持续卡题、最近失败和推荐练习题，并从现有编程题中下发 1–10 道专项练习。题目选择器支持按管理员保存的分类标签与标题关键词组合搜索。

老师可以看到其他老师已经下发的任务及学生进度，但只能编辑、归档或删除自己创建的任务。自己创建且未归档的任务可继续增题、删题、上下排序，并与标题、说明、截止时间一次性保存；取消编辑会恢复服务器顺序。删除已完成题会强提醒，只解除任务关联并重算进度，不删除历史提交或代码；完成任务加入新题后会重新变为进行中，新题不继承历史 AC。其他老师创建的任务显示“仅查看”；访问其修改接口时统一返回不存在。

老师新建或保存修改后的专项练习，会在学生下次进入或刷新首页时加入未完成任务汇总提醒。学生只能通过“去完成专项练习”进入任务列表；点击后相同任务版本静默 60 分钟，期间刷新或重新登录不会重复弹出。满 60 分钟后仅在学生首页重新读取状态并按未完成情况提醒；新任务或再次修改会在下一次首页读取时立即触发。该提醒不做实时推送，也不会在做题、考试或专项练习页面打断学生。

## 8. AI 使用和天梯

页面：

```text
/teacher/ai-usage
/teacher/ai-usage/[studentId]
/teacher/leaderboard
```

老师可以审阅学生实际看见的 AI 提问与回复，查看使用次数、模型调用、缓存、失败和 Token 统计，并查看全体学生天梯。

老师只能使用管理员已经配置好的 AI 服务商和模型，不能查看或修改 API Key。API Key 始终只保存在服务器 `.env`。

选择判断题 AI 解析不受学生个人 AI 权限、日常练习 AI 或考试 AI 开关影响，只受管理员的独立全局开关控制。解析使用数据库标准答案，老师和模型都不能修改判定答案；解析不计入学生 AI 使用统计。

## 9. 权限异常处理

- 访问自己的考试却显示不存在：确认当前登录的老师账号是否就是考试创建者。
- 看得到专项练习但不能编辑：该任务由其他老师或管理员创建，当前老师只有查看权限。
- 学生看不到 AI：同时检查学生个人 AI 权限，以及日常练习或当前考试的 AI 开关。
- 需要新题、导入题目或调整题序：联系管理员处理。
- 需要创建老师或修改老师角色：联系管理员处理。
